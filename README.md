# 연차 결재 대작전

3D 사무실을 돌아다니며 여섯 명에게 차례로 연차 결재를 받는 페이지예요. 휴대폰에서 열 수 있어요.

- 주인공이 엘리베이터에서 내려 옆자리 → 파트장 → 회의실 팀장 → 인사팀 → 탕비실 막내 → 대표실 순서로 찾아가요.
- 대화는 말풍선으로 한 줄씩 나오고, 대화가 끝나면 "승인" 도장이 찍혀요. 아래 신청서 칸에도 도장이 채워져요.
- 대화 중에 3D 화면을 탭하면 다음 대사로 넘어가요. 신청서 칸을 누르면 그 사람 장면으로 바로 가요.

## 이름·대사 바꾸기

`index.html` 맨 위 `HERO`, `PEOPLE`, `SCENES`, `FINALE`만 고치면 돼요.

- `PEOPLE`: 이름, 역할, 옷 색, 머리 모양(`short` `side` `part` `long` `ponytail` `bald`), 안경, 넥타이
- `SCENES`: 각 사람과의 대사. `'me'`는 주인공, `'npc'`는 상대

## 배포

저장소 **Settings → Pages**에서 Branch를 `main` / `/ (root)`로 고르고 저장하면 `https://cho-seoyeon.github.io/vacation_request/`에서 열려요.
