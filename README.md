# 반차 결재 대작전

지하주차장에 차를 대고 엘리베이터를 타고 올라와서, IT 회사 사무실을 돌며 18일 오후 반차 결재를 받는 3D 페이지예요. 휴대폰에서 열 수 있어요.

1. **B1 주차장**: 차를 대고 유리 엘리베이터에 타요.
2. **엘리베이터 안**: 올라가는 동안 속마음 말풍선이 나와요.
3. **내 자리**: 고민하다가 왼쪽 주임님께 말해요. 오른쪽 사수님이 궁시렁대면 속마음이 튀어나와요. 주임님이 승인해요.
4. **팀장님**: "○○ 주임한테 컨펌 받았어요?" → "넵." → OK
5. **지사장님**: 자리에서 결재를 올려요. 승인/반려를 직접 골라요.
6. **탕비실의 시운 · 희연 · 선혜 주임님**: 셋이 서서 수다 떨다가 소식을 들어요. 승인이면 하트가 나오며 축하하고, 반려면 다 같이 화내다가 "쾅!"

- 대화 중에 3D 화면을 탭하면 다음 대사로 넘어가요.
- 신청서 결재 칸을 누르면 그 장면으로 가요. "다른 결말"을 누르면 반대 결말을 볼 수 있어요.

## 대사·생김새 바꾸기

`index.html` 맨 위 `CAST`(등장인물)와 `SCRIPT`(대사)만 고치면 돼요. 인물 그림은 `img/` 폴더에 있어요. 대사 끝에 `'think'`를 붙이면 속마음 말풍선이 돼요.

## 배포

저장소 **Settings → Pages**에서 Branch를 `main` / `/ (root)`로 고르면 `https://cho-seoyeon.github.io/vacation_request/`에서 열려요.
