# 3D 인물 모델

이 폴더에 `.glb` 파일을 넣으면 그 인물이 그림 대신 3D 모델로 바뀌어요. 파일이 없으면 지금 그림 피규어가 그대로 나와요.

| 파일 이름 | 인물 |
| --- | --- |
| `me.glb` | 나 |
| `approver.glb` | 왼쪽 자리 주임님 |
| `senior.glb` | 오른쪽 자리 사수님 |
| `lead.glb` | 팀장님 |
| `boss.glb` | 지사장님 |
| `shiun.glb` | 시운 주임님 |
| `heeyeon.glb` | 희연 주임님 |
| `sunhye.glb` | 선혜 주임님 |

- 크기와 바닥 위치는 자동으로 맞춰져요.
- 애니메이션 이름에 `walk`/`run`이 들어가면 걸을 때, `idle`이 들어가면 서 있을 때 재생돼요.
